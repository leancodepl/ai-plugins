# Changelog

## 0.1.0

First public release, carried over from LeanCode's internal marketplace at the same version.

- `skills/publish-flitz-bundle/SKILL.md`: run `flitz publish --yes --json` in the project directory and report the landing page. Installs the CLI when missing, and sets a placeholder `FLITZ_APIKEY` for the Claude Tag Agent Proxy when no other credential exists.
- `skills/lean-flitz-usage/SKILL.md`: what the plugin does, where it runs, and what it needs.
- The README explains Flitz itself and what a project needs before the skill can publish, for readers who have not used it.
