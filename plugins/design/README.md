# design

Art direction plugin for Claude Code, for visual and copy work that should not look AI-generated.

Contains:

- `skills/deslopify/SKILL.md`: banned visual patterns, composition and grid, typography, colour, copy rules and a review checklist
- `skills/design-usage/SKILL.md`: entry point for this plugin

## Example usage

- `/design:deslopify`: direct or review a landing section, artifact, Figma frame or UI mockup
- `/design-usage`: get a short explanation of what this plugin does and which asset to use next

## What this plugin is NOT about

Implementing Flutter UI from a design system lives in [`flutter-ui`](../flutter-ui/).

## Related plugins

- [`flutter-ui`](../flutter-ui/): Figma-driven Flutter UI implementation and design-system usage
